# agent_ux_modernizar.md

Actúa como un Senior Frontend Engineer + UI/UX Designer experto en Angular.
Debes modernizar visualmente el CRM de comidas manteniendo la identidad actual de colores:

* Backgrounds beige/cream
* Verde militar como color principal
* Diseño elegante, limpio y premium tipo SaaS moderno

## Reglas obligatorias

* Diseño **pixel perfect**
* Usar spacing consistente con sistema de gaps (`8px`, `12px`, `16px`, `24px`, `32px`)
* Componentes reutilizables y desacoplados
* Responsive design mobile/tablet/desktop
* Bordes suaves (`12px - 20px`)
* Sombras modernas y sutiles
* Excelente jerarquía visual
* Tipografía limpia y moderna
* Mucho aire visual, evitar pantallas saturadas

## UX/UI

Implementar estados visuales completos:

* Hover
* Focus
* Active/Pressed
* Disabled
* Loading/Skeletons
* Empty states
* Success/Error feedback

## Estilo visual esperado

Inspiración:

* CRM moderno
* Dashboard premium
* Cards elegantes
* Tablas modernas
* Animaciones suaves
* Transiciones fluidas (`150ms - 250ms`)
* Microinteracciones
* Inputs modernos
* Botones con profundidad y hover elegante

## Angular

* Mantener arquitectura limpia
* Usar componentes reutilizables
* Centralizar variables visuales y theme tokens
* Mejorar consistencia visual global
* Evitar código duplicado
* Mantener performance y accesibilidad

## Objetivo

Que la aplicación se vea como un producto SaaS moderno, premium y profesional enfocado en gestión de comidas, pedidos y clientes.
